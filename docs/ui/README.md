# Guía de interfaz de usuario

## Principios generales

- Interfaz completamente en español.
- Barra lateral negra, angosta, con iconos blancos.
- Contenido principal con espacios amplios.
- Panel derecho de previsualización donde corresponda.
- Sin footer.
- Sin encabezados gigantes.
- Formularios preferiblemente en modales o paneles laterales.
- Iconos discretos (Lucide React).
